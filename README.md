
# TankFiring 5星坦克属性计算器

一个用于《TankFiring》游戏的坦克属性计算工具，支持等级、勋章、五星坦克加成和已升级状态的实时计算。

## 功能特性

- 📊 支持15种坦克的属性查询
- 🎯 等级 1-13 选择
- 🎖️ 勋章等级 0-250
- ⭐ 五星坦克加成 0-65%
- 🚀 已升级状态：基础值提前 +4.5%（13级禁用）
- 🔒 提供加密版和混淆版
- 📱 移动端优先设计

## 使用方法

### 网页版
直接打开 HTML 文件即可使用：
- `TankFiring_坦克属性查询.html` - 标准版
- `TankFiring_坦克属性计算器_加密版.html` - 加密隐藏版（源码不可见）
- `TankFiring_坦克属性计算器_混淆版.html` - 混淆隐藏版（源码混淆）

### 桌面版
需要 Python 环境：
```bash
python TankFiring_坦克属性查询.py
```

## 核心算法

**已升级**（1-12级可用）：
1. 选择属性基础值 × 1.045
2. 加上勋章累加值
3. 加上五星坦克加成（可选）
4. 结果四舍五入取整

**13级**：已升级功能禁用，仅计算基础值 × 1.045
